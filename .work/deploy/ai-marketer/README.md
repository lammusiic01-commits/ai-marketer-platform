# AI Marketer Platform

Локальная SaaS-платформа для маркетинговых команд: SEO/GEO-аудиты, антибот-аналитика, конкуренты, генерация кампаний и текстов, ROI, гипотезы, отчёты, клиенты и канбан-задачи в рабочих пространствах.

## Запуск в Windows
1. Установите Python 3.11+ и Node.js 20+.
2. Дважды щёлкните `start.bat`. Скрипт создаст `venv`, установит зависимости, соберёт интерфейс и откроет `http://localhost:8000`.
3. Зарегистрируйте аккаунт: приложение создаст пользователя и рабочее пространство «Моя команда».

В `.env` создаются уникальные локальные JWT- и Fernet-ключи. OpenRouter-ключ можно добавить в `OPENROUTER_API_KEY`; без него локальные анализаторы и остальные разделы работают, а AI-модули показывают явное сообщение о необходимости ключа. Настройки SMTP можно заполнить для отправки приглашений; без SMTP ссылка приглашения записывается в журнал приложения и возвращается API.

## Разработка
- Backend: `venv\\Scripts\\activate` и `python main.py`.
- Frontend: `cd frontend`, `npm install`, `npm run dev`.
- OpenAPI: `http://localhost:8000/docs`.
- Health check: `http://localhost:8000/api/healthz`.
- Runtime route manifest: `http://localhost:8000/manus-routes.json`.

## База данных и production
По умолчанию используется SQLite (`data.db`) — отдельные установки работают локально без внешней БД. Для production задайте `DATABASE_URL` с PostgreSQL URL; приложение нормализует стандартные `postgres://`/`postgresql://` в async-драйвер `asyncpg`. В production также замените `JWT_SECRET`, задайте отдельный Fernet `ENCRYPTION_KEY`, `APP_URL`, SMTP и `OPENROUTER_API_KEY`. Реальные данные Яндекс.Метрики/Директа требуют токенов соответствующих сервисов; аналитические формы принимают данные пользователя, а интеграции хранятся в зашифрованном виде.

Не публикуйте `.env` и `data.db`.
